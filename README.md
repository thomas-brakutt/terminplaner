# Terminplaner

Ein webbasiertes Terminverwaltungssystem, das ich als
Lern- und Portfolio-Projekt entwickle.

## Projektziel

Mit dieser Anwendung sollen Benutzer Termine
erstellen, anzeigen, bearbeiten und löschen können.

## Technologien

- HTML5
- CSS3
- JavaScript

Später geplant:

- Java
- Spring Boot
- Datenbank

## Projektstatus

Das Projekt befindet sich in der Entwicklung.

Aktueller Stand:

- Git-Repository eingerichtet
- GitHub-Repository erstellt

## Geplante Funktionen

- Termine erstellen
- Termine bearbeiten
- Termine löschen
- Termine nach Datum sortieren
- Terminüberschneidungen erkennen
- Termine dauerhaft speichern
